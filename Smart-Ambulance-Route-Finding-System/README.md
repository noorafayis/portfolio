Smart Ambulance Route Finding System

Project Description
This is a group mini-project developed using Prolog. The system finds suitable routes for ambulances by considering road distance, travel time, traffic conditions, and blocked roads.

Technologies Used
- Prolog
- Artificial Intelligence
- Search Algorithms

Main Features
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- A* Search Algorithm
- Blocked road detection
- Traffic information management
- Route comparison
- Distance and travel time calculation

My Contribution
I contributed to Road Network and Traffic Management, including road distance and time facts, blocked road information, traffic conditions, traffic cost calculation, and road availability checking.
